# Tic Tac Toe Game

## Description
A console-based Tic Tac Toe game developed using C++.

## Features
- Two player gameplay
- Dynamic board display
- Win detection
- Draw detection
- Replay option

## Concepts Used
- Arrays
- Loops
- Conditional statements
- Functions

## How to Run

Compile:
g++ main.cpp -o tictactoe

Run:
.\tictactoe

## Language
C++
